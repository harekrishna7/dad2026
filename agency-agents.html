What Is It

Your dream team, except they never sleep

Specialised

Deep expertise in each domain — not generic prompt templates. Every agent is crafted for a specific job, from engineering and design to marketing and security.

Personality-Driven

Unique voice, communication style and approach for every agent — so working with them feels like collaborating with a real specialist, not a blank chat box.

Deliverable-Focused

Real code, real processes, measurable outcomes. Each agent file ships with workflows, technical deliverables, code examples and success metrics.

Production-Ready

Battle-tested workflows and success metrics, refined over months of iteration — born from a Reddit thread and grown into a structured roster.

Install Anywhere

One-command installers for Claude Code, Cursor, Codex, Gemini CLI, OpenCode, Qwen, Osaurus, Aider, Windsurf, Copilot and more.

Community-Grown

A living, open collection — PRs welcome. The roster keeps expanding as new specialists join the agency.

Quick Start
# Install the agents into your preferred tool
./scripts/install.sh --tool claude-code

# Or generate integrations for every supported tool
./scripts/convert.sh

# Target one division, or pick specific agents
./scripts/install.sh --tool cursor --division engineering,security
./scripts/install.sh --tool gemini-cli --agent frontend-developer,ui-designer

Built on Shell, Python and PowerShell scripts that convert the markdown roster into per-tool agent files — with CI checks keeping the division list, tool integrations and agent definitions in sync.
