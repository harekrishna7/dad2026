# DADsync GitHub Pages Deployment

This repository deploys the DADsync website to GitHub Pages.

## Files
- `index.html` — homepage
- `about.html`, `services.html`, `hub.html`, `connection.html`, `industries.html`, `careers.html`, `investors.html`, `news.html`, `contact.html`, `privacy.html`, `terms.html` — pages
- `assets/styles.css` — stylesheet
- `assets/app.js` — site scripts
- `assets/firebase-config.js` — Firebase configuration for forms
- `assets/downloads/` — PDF documents
- `images/` — site images

## Deploy
Push to `main` branch. GitHub Actions / Pages serves the site from the root.
